# GPT Image 2.5 调用工具

一个**零依赖、单文件**的网页工具，用于调用 OpenAI 的 **GPT Image 2.5** 图像接口（`gpt-image-2.5-flare` / `gpt-image-2.5-sunburst`）。

双击 `index.html` 就能用：不用装 Python / Node / 任何依赖，也不用起服务。

---

## 功能一览

| 能力 | 说明 |
| --- | --- |
| 模型切换 | 卡片式单选 **Flare / Sunburst**，可一键锁定快照版本 `-2026-09-08`，也可直接填自定义模型 ID |
| 文生图 | `POST /v1/images/generations` |
| 图生图 / 编辑 | `POST /v1/images/edits`，最多 16 张参考图 + PNG 透明蒙版局部重绘。样图可在提示词框左下角**点按钮上传**，也可**拖拽**或 **Ctrl+V 粘贴** |
| 全参数 | `n` / `size` / `resolution` / `quality` / `output_format` / `output_compression` / `background` / `moderation` / `partial_images`(流式) / `user` |
| 实时预览 | 流式模式下分片预览，出图即显示 |
| 费用预估 | 发送前按尺寸 × 质量给出 token 与美元预估；返回后按真实 `usage` 结算显示实际费用 |
| 请求预览 | 自动生成可直接复制执行的 `curl` 命令 |
| 异步网关 | 兼容返回 `task_id` 的中转服务，自动轮询任务结果 |
| 结果处理 | 网格预览、放大、单张下载、批量下载、复制 Base64、原始响应 JSON |
| 配置记忆 | 可选把配置（含 API Key）存到本机 `localStorage` |

## 快速开始

1. 双击打开 [index.html](index.html)。
2. 填 **API Key**（`sk-...`）。Base URL 默认 `https://api.openai.com`。
3. 选模型：**Flare**（默认，快）或 **Sunburst**（精修准）。
4. 写提示词，调参数，点「开始生成」。
5. 出图后可单张下载 / 批量下载 / 复制 Base64。

### 改图：在提示词框里直接丢样图

提示词和参考图是**同一个输入框**：

```
┌─────────────────────────────────────────────┐
│  [样图1] [样图2] [蒙版] [+]                 │  ← 上传后出现在这里
│                                             │
│  把背景换成米白影棚，保留商品和文字不变…    │  ← 提示词
│                                             │
│  [🖼 上传样图] [◐ 蒙版] 可拖拽/粘贴  … 示例 │  ← 左下角上传按钮
└─────────────────────────────────────────────┘
```

三种加图方式，效果一样：

1. 点左下角 **「🖼 上传样图」**（可多选，最多 16 张）
2. 把图片**直接拖进**输入框
3. 复制图片后在输入框里 **Ctrl+V 粘贴**（截图也能直接粘）

加上样图后会**自动切到「图生图 / 编辑」模式**；把样图全部移除会自动切回「文生图」。缩略图右上角的 × 可以单独删掉某张，点缩略图可放大预览。

**蒙版**：点「◐ 蒙版」上传 PNG（透明区域 = 要重绘的区域），缩略图上会标出「蒙版」角标。

**用图片 URL**：展开输入框下方的「用图片 URL 代替本地文件」，每行一个，可与本地样图混用。

> 需要 **Tier 1 及以上**的付费账号才能调用图像接口，ChatGPT 订阅不算。

### 用第三方中转

Base URL 填中转站地址（**不要带 `/v1`**），例如 `https://api.example.com`。
如果中转返回的是 `task_id`，勾选参数区底部的 **「异步网关模式」**，工具会自动轮询任务直到出图。

## 模型怎么选

| 模型 | 定位 | 适用场景 |
| --- | --- | --- |
| `gpt-image-2.5-flare` | 默认选项，**更快**（比上一代延迟低约 50%） | 社交内容、商品图、批量生成、快速原型 |
| `gpt-image-2.5-sunburst` | **编辑精度优先**，速度慢一些 | 生产级商品图、广告素材、多轮精细编辑 |

两者**同价**，选谁只是「速度 ↔ 编辑精度」的取舍。不确定就先用 Flare。

想锁定输出稳定，勾选「锁定快照版本」，模型 ID 会变成 `gpt-image-2.5-flare-2026-09-08` 这种形式。

## 参数详解

### 通用参数

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| `model` | `gpt-image-2.5-flare` / `gpt-image-2.5-sunburst` | 必填 |
| `prompt` | 文本 | 必填。描述主体、场景、构图、风格、光线，以及要保留 / 要改的部分 |
| `n` | 1 ~ 4 | 一次生成几张 |
| `size` | `auto` / 精确像素 / 宽高比 | 见下方尺寸说明 |
| `resolution` | `1k` / `2k` / `4k` | 仅当 `size` 用宽高比时生效；填精确像素时忽略 |
| `quality` | `auto` `low` `medium` `high` `xhigh` `max` | `xhigh` / `max` 是 2.5 新增档位，发给 2 代会返回 400 |
| `output_format` | `png` `jpeg` `webp` | 默认 `png`；jpeg 更快更小 |
| `output_compression` | 0 ~ 100 | **仅 jpeg / webp 生效** |
| `background` | `auto` `opaque` `transparent` | `transparent` 必须配 png 或 webp，配 jpeg 会报错（工具已做前置校验） |
| `moderation` | `auto` `low` | `low` 会放宽内容审核阈值 |
| `partial_images` | 0 ~ 3 | 流式分片预览；每片额外计 **100 输出 token** |
| `user` | 字符串 | 可选的调用方标识，用于风控追踪 |

### 编辑专用参数

| 参数 | 说明 |
| --- | --- |
| `image` / `image[]` | 参考图。multipart 表单上传本地文件，或改用 JSON 模式传 `image_urls` |
| `image_urls` | 参考图 URL 数组，最多 16 张（JSON 模式） |
| `mask` / `mask_url` | 蒙版。**PNG 且带 alpha 通道**，尺寸需与第一张参考图完全一致；**全透明像素 = 要重绘的区域** |
| `input_fidelity` | `low` / `high`，控制对参考图的还原程度；留空则不发送该字段（部分网关不支持） |

编辑模式提供两种请求格式：

- **multipart/form-data**：OpenAI 官方 `/v1/images/edits` 的标准写法。
- **JSON + image_urls**：部分中转网关的写法，本地文件会自动转成 data URL。

## 尺寸规则

### 精确像素

- 宽高都必须是 **16 的倍数**
- 单边 **≤ 3840**
- 长短边比 **≤ 3:1**
- 总像素 **655,360 ~ 8,294,400**

官方推荐三档：`1024x1024`、`1536x1024`、`1024x1536`。工具内置了常见尺寸下拉框，也支持自定义宽高（带实时校验）。

### 宽高比 + 分辨率

支持 15 种比例：`1:1` `3:2` `2:3` `4:3` `3:4` `5:4` `4:5` `16:9` `9:16` `2:1` `1:2` `21:9` `9:21` `3:1` `1:3`，搭配 `1k` / `2k` / `4k`。

## 常见问题

**浏览器直连报 CORS / 跨域错误？**
官方 `api.openai.com` 允许浏览器直连。如果被拦截，通常是网络环境或用了不允许跨域的中转，换一个 Base URL 即可。

**报 429 限流？**
工具会读取 `Retry-After` 自动重试（次数可配）。图像接口的配额是**每分钟图片数**，降并发即可。

**`insufficient_quota`？**
账号没余额或还在免费层，需要充值，重试无用。

**提示被内容审核拦截？**
改写提示词，而不是重试；把 `moderation` 设为 `low` 可以放宽阈值。

**超时？**
复杂提示词官方文档说最长可能处理 2 分钟，Sunburst 比 Flare 更慢。工具默认超时 180 秒，可在「接口配置」里调大。

**API Key 安全吗？**
工具是纯前端页面，Key 只在你本机浏览器里，直接发给你填的 Base URL。不勾选「记住配置」就不会落盘。
